# Security Policy

## Supported Versions

This reference has no supported public release while its version is
`0.0.0-private` and publication is on hold. Security fixes should target the
current private branch only.

## Reporting a Vulnerability

Do not place credentials, exploit details, personal data, or private repository
content in a public issue. Use GitHub private vulnerability reporting if the
future repository enables it. Otherwise, contact the repository owner through
a private channel that the owner has explicitly published for security reports.

No reporting address, response time, or disclosure window is invented in this
reference. The owner must configure a real private reporting channel and record
it in the publication checklist before release.

## Scope

Reports may cover the validation scripts, workflow permissions, agent or skill
trust boundaries, sanitization gaps, secret-detection gaps, and examples that
could teach unsafe behavior. This repository contains no application runtime or
production service to test.
