# Support

## Questions and Ideas

Open an issue and choose the question or feature request option that best fits
your topic. GitHub Discussions may be enabled later if community volume makes a
separate forum useful.

Before posting, search existing issues and read the
[project documentation](README.md#documentation). Include the client, version,
operating system, relevant files, and the smallest safe reproduction that helps
others understand the problem.

## Bugs

Use the bug-report issue form. Include the expected and observed behavior and
the exact verification commands that ran. Remove credentials, private domains,
customer information, and proprietary repository content.

## Security

Do not request security help in a public issue. Follow
[`SECURITY.md`](SECURITY.md) and use private vulnerability reporting.
